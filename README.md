# Maze Puzzle Game

A university project for the **Game Design** course.  
This project implements a maze-based puzzle game with multiple logical challenges, scoring mechanics, teleportation, fog-of-war areas, and item-based progression.

## 🎯 Project Overview

The game is played on a grid-based maze where the player must navigate from the entrance to the exit while solving puzzles and managing score.

Key gameplay elements:
- Maze navigation with movement penalties
- Puzzle-based walls that unlock new paths
- Teleport and portal mechanics
- Fog-of-war regions
- Item collection system
- Score-based ranking system

## 🧩 Implemented Puzzles

The game includes several puzzle types:

1. **Cube Unfolding Puzzle**  
   Spatial reasoning challenge where the player identifies the correct unfolded cube.

2. **Visual Algebra Puzzle**  
   Pattern recognition and logical reasoning based on symbolic equations.

3. **Murder Mystery Puzzle**  
   Deductive reasoning using witness reliability and conflicting evidence.

4. **Word Search Puzzle**  
   Hidden word discovery across multiple directions.

5. **Circle of Life Puzzle**  
   Resource management and survival across seasonal stages.

## 🧠 Game Mechanics

- Each move reduces player score
- Re-entering cells increases penalties
- Fog regions limit visibility
- Teleports move the player across the map
- Players must collect seasonal items in order:
  Spring → Summer → Autumn → Winter
- Final exit unlocks after collecting all required items

## 🏆 Scoring System

- Initial score: 2000
- Puzzle solving increases score
- Incorrect attempts decrease score
- Movement and repeated visits apply penalties
- Final score determines rank: S / A / B / C
